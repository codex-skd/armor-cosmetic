<h2>v1.0.0 - First Stable Release for Minecraft 26.2</h2>

<h3>Changes</h3>
<ul>
<li><strong>Port to 26.2</strong>: Full port to Minecraft 26.2 / NeoForge 26.2.0.32-beta.</li>
<li><strong>API fixes</strong>: <code>setScreen</code> renamed to <code>setScreenAndShow</code>, <code>screen</code> field moved to <code>gui.screen()</code>.</li>
<li><strong>Updated skeleton</strong>: Template 26.2-26.2.0.32-beta used as project base.</li>
<li><strong>Translations</strong>: Fixed encoding issues in Spanish (es_es.json) - UTF-8 corrupted characters corrected.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>GuiHandler</code> — replaced <code>getMinecraft()</code> with <code>Minecraft.getInstance()</code>.</li>
<li><code>KeyHandler</code> — replaced <code>mc.screen</code> with <code>mc.gui.screen()</code>.</li>
<li><code>GuiCosArmorInventory</code> — replaced <code>setScreen</code> with <code>setScreenAndShow</code>.</li>
</ul>
