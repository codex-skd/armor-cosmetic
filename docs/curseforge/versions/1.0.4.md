<h2>v1.0.4 - Cosmetic Data Save Crash Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Cosmetic armor data failing to save on logout/server stop</strong>: <code>IllegalStateException: Can't access registry ResourceKey[minecraft:root / minecraft:enchantment]</code> when saving a player's cosmetic armor inventory. The serialization code was encoding/decoding <code>ItemStack</code> data with a plain NBT codec that has no registry access, instead of using the server's registry lookup, so any item referencing registry-backed data (e.g. enchantments) failed to serialize and the player's cosmetic armor was silently lost on logout.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>CAStacksBase.serializeNBT</code> / <code>deserializeNBT</code> — now encode/decode <code>ItemStack</code> through <code>provider.createSerializationContext(NbtOps.INSTANCE)</code> instead of raw <code>NbtOps.INSTANCE</code>, so the registry access already passed into these methods is actually used.</li>
</ul>

<blockquote>Server owners: this fixes silent data loss of cosmetic armor on player disconnect and on server shutdown. Update as soon as possible.</blockquote>
