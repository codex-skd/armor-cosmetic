<h2>v1.0.6 - Inventory Synchronization Fix & Player Rendering</h2>

<h3>Bug Fix</h3>
<blockquote><strong>Inventory Desynchronization:</strong> Fixed critical bug where switching from cosmetic inventory back to normal inventory would close the normal inventory unexpectedly and become uninteractive. The issue was caused by inconsistent client-server communication when closing the cosmetic container. Server now properly closes the cosmetic menu without requiring manual client-side screen management.</blockquote>

<h3>New Feature</h3>
<blockquote><strong>Player Avatar Preview:</strong> Added player model rendering directly in the cosmetic inventory screen. The player character now displays with your currently equipped cosmetic armor, rotating smoothly to follow your mouse movement. This allows you to see how cosmetics look on your character in real-time while browsing and equipping items.</blockquote>

<h3>Technical Details</h3>
<ul>
<li>Implemented <code>EntityRenderState</code> rendering using NeoForge 26.2 <code>GuiGraphicsExtractor.entity()</code> API</li>
<li>Player preview rotates based on mouse position for interactive preview</li>
<li>Synchronized inventory switching between normal and cosmetic screens (client-server)</li>
</ul>
