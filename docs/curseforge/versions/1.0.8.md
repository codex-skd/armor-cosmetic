<h2>v1.0.8 - GUI Polish & Final Refinements</h2>

<h3>Bug Fixes</h3>

<h4>Player Avatar Position Correction</h4>
<blockquote>Adjusted player model positioning to match the vanilla inventory screen. The avatar now appears in the center-left area of the cosmetic inventory, providing a consistent visual experience between normal and cosmetic inventory screens.</blockquote>

<h4>Close Button Behavior Fix</h4>
<blockquote>Fixed the close button in the cosmetic inventory screen to properly return to the normal inventory. The button now opens the <code>InventoryScreen</code> directly instead of just closing, ensuring smooth transitions between inventory modes and preventing UI state confusion.</blockquote>

<h3>Technical Changes</h3>
<ul>
<li>Repositioned avatar render bounds for better visual alignment</li>
<li>Updated rotation center point to match new positioning</li>
<li>Enhanced client-side inventory switching logic</li>
<li>Improved UI responsiveness on inventory transitions</li>
</ul>

<h3>Summary</h3>
<p>This patch release focuses on fine-tuning the GUI experience with precise positioning adjustments and improved button behavior, making the cosmetic inventory feel more polished and responsive.</p>
