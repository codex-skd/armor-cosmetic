<h2>v1.0.3 - Dedicated Server Crash Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Server crash on load</strong>: <code>NoClassDefFoundError: net/minecraft/client/gui/screens/Screen</code>. The <code>IConfigScreenFactory</code> registration in the main mod constructor (which runs on both client and dedicated server) was touching the client-only <code>ConfigurationScreen</code> class unconditionally, crashing dedicated servers on load.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ArmorCosmetic</code> — wrapped <code>registerExtensionPoint(IConfigScreenFactory.class, ConfigurationScreen::new)</code> in a <code>FMLEnvironment.getDist() == Dist.CLIENT</code> check so the class is never linked on the server classloader.</li>
</ul>

<h3>Notes</h3>
<blockquote>Server owners: this fixes a hard crash on startup introduced in 1.0.1. Update immediately if running a dedicated server.</blockquote>
