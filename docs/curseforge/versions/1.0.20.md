## v1.0.20 — Tombstone Compatibility: Real Armor Captured

### 🐛 Fix
- **Real armor lost on death with Tombstone**: The player's real armor is now added to `LivingDropsEvent` alongside cosmetic armor. This ensures Tombstone captures both the real and cosmetic armor into the grave.

### 🛠️ Technical Changes
- `InventoryManager.handlePlayerDrops()` now iterates the player's armor slots (head, chest, legs, feet) and adds those items to `event.getDrops()`.
- Real armor items are cleared from the player inventory after being added to drops.
- This guarantees compatibility with Tombstone regardless of how it internally handles drops.
