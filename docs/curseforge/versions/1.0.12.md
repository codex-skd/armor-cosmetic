<h2>v1.0.12 - Player Rendering Position and Close Button Improvements</h2>

<h3>Fix</h3>
<ul>
<li><strong>Player Model Position</strong>: Repositioned the player preview from center to the upper-right area of the cosmetic armor inventory screen, matching the intended visual layout.</li>
<li><strong>Player Preview Size</strong>: Increased player model rendering size from 40 to 50 pixels for better visibility and detail.</li>
<li><strong>Close Button Responsiveness</strong>: Enlarged the close button (✕) from 16x16 to 20x20 pixels for improved clickability and accessibility. Adjusted positioning for optimal placement.</li>
<li><strong>Dynamic Center Point Calculation</strong>: Improved mouse interaction calculations by computing center point dynamically from the rendering area bounds instead of fixed coordinates.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Modified <code>GuiCosArmorInventory.renderPlayerPreview()</code> to adjust rendering coordinates and size parameters.</li>
<li>Enhanced button builder configuration for better visual feedback and interaction response.</li>
</ul>

<br>

<blockquote>
This release focuses on UI/UX improvements to the cosmetic armor inventory interface, making the player preview more prominently displayed and the close button more accessible to users.
</blockquote>
