<h2>v1.0.13 - Player Position Fix and Close Button Improvements</h2>

<h3>Fix</h3>
<ul>
<li><strong>Player Avatar Position</strong>: Repositioned the player model to the left side of the cosmetic armor inventory screen (matching vanilla inventory proportions: coordinates from <code>leftPos + 26</code> to <code>leftPos + 76</code>, <code>topPos + 8</code> to <code>topPos + 78</code>). Size reduced from 50 to 30 pixels to align with standard inventory rendering.</li>
<li><strong>Close Button Tooltip (✕)</strong>: Added <code>"cos.gui.tooltip.close"</code> ("Close Cosmetic Inventory") tooltip to the close button, improving UI accessibility and clarity.</li>
<li><strong>Normal Inventory Interaction After Closing</strong>: Fixed critical bug where the ✕ button created a client-only <code>InventoryScreen</code> without notifying the server, causing the normal inventory to be unresponsive. Now sends <code>PayloadOpenNormalInventory</code> to the server, which properly executes <code>doCloseContainer()</code> for correct state synchronization.</li>
<li><strong>Close Tooltip Translations</strong>: Added <code>cos.gui.tooltip.close</code> key across all 15 supported languages (es_es: "Cerrar Inventario Cosmético", en_us: "Close Cosmetic Inventory", and all others).</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Modified <code>GuiCosArmorInventory.renderPlayerPreview()</code> to use vanilla-style coordinates on the left side of the GUI.</li>
<li>Replaced direct <code>setScreenAndShow()</code> call with proper network packet dispatch for container closure.</li>
<li>Added <code>Tooltip.create()</code> and <code>PayloadOpenNormalInventory</code> imports and usage.</li>
</ul>

<br>

This release fixes the player preview positioning to match the cosmetic inventory layout and resolves an issue where the normal inventory became non-functional after closing the cosmetic inventory with the ✕ button.
</blockquote>
