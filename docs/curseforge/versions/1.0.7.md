<h2>v1.0.7 - UI Improvements & Multi-Language Support</h2>

<h3>Improvements</h3>

<h4>Player Avatar Repositioning</h4>
<blockquote>Fixed player model positioning in the cosmetic inventory screen. The character avatar now appears correctly on the right side of the interface instead of overlapping with armor slots. Increased preview size from 30 to 40 pixels for better visibility, and optimized rotation center for smooth mouse-following animations.</blockquote>

<h4>Inventory Close Button Enhancement</h4>
<blockquote>Improved the robustness of the close button when exiting the cosmetic inventory. The server now explicitly sends the container close packet to ensure proper synchronization between client and server when returning to the normal inventory.</blockquote>

<h3>New Features</h3>

<h4>Expanded Language Support</h4>
<blockquote>Added support for 4 new languages, expanding from 11 to 15 total languages:
<ul>
<li><strong>Italian (Italiano)</strong> - it_it</li>
<li><strong>Dutch (Nederlands)</strong> - nl_nl</li>
<li><strong>Swedish (Svenska)</strong> - sv_se</li>
<li><strong>Polish (Polski)</strong> - pl_pl</li>
</ul>
The mod now has comprehensive support for European languages alongside existing translations.</blockquote>

<h3>Summary</h3>
<p>This release focuses on user experience improvements with better GUI positioning, more reliable inventory management, and significantly expanded language support for international players.</p>
