<h2>v1.0.1 - Config screen fix for NeoForge 26.2</h2>

<h3>Fix</h3>
<ul>
<li><strong>Config screen not showing</strong>: Moved <code>IConfigScreenFactory</code> registration from <code>ArmorCosmeticClient</code> (client-only <code>@Mod</code>) to the main <code>ArmorCosmetic</code> constructor. In NeoForge 26.2, <code>@Mod</code> classes with <code>dist = Dist.CLIENT</code> may not be loaded, preventing the configuration button from appearing in the mods menu.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li><code>ArmorCosmeticClient</code> — converted from <code>@Mod</code> to <code>@EventBusSubscriber</code>.</li>
<li><code>ArmorCosmetic</code> — <code>registerExtensionPoint(IConfigScreenFactory.class, ConfigurationScreen::new)</code> added to constructor.</li>
</ul>
