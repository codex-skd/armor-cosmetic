<h2>v1.0.16 - Inventory Transition Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Inventory Transition After Closing Cosmetic</strong>: Fixed the ✕ close button to properly transition from the cosmetic inventory back to the normal inventory. The button now sends the close packet to the server and defers the <code>InventoryScreen</code> opening to the next render frame via <code>extractRenderState</code>, ensuring the server has processed the container close before the client attempts to interact with the normal inventory slots.</li>
</ul>

<br>

<blockquote>
This hotfix resolves the inventory interaction issue by properly deferring the screen transition until after the server has closed the cosmetic container.
