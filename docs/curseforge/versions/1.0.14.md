<h2>v1.0.14 - Duplicate Button Removal &amp; Close Button Fix</h2>

<h3>Fix</h3>
<ul>
<li><strong>Duplicate Toggle Button Removed</strong>: The cosmetic armor toggle button (<code>GuiCosArmorButton</code>) no longer appears on the cosmetic armor inventory screen. It was redundant alongside the dedicated ✕ close button. The toggle now only shows on the normal inventory screen where it belongs.</li>
<li><strong>Close Button (✕) Now Works</strong>: Fixed the ✕ button which was sending the close packet to the server but failing to show the normal inventory screen. Now it both synchronizes server state via <code>PayloadOpenNormalInventory</code> and immediately displays the <code>InventoryScreen</code> for a seamless transition back to the normal inventory.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Split <code>GuiHandler.handleGuiInitPost()</code> to handle <code>InventoryScreen</code> and <code>GuiCosArmorInventory</code> separately, removing the toggle button from the cosmetic screen.</li>
<li>Restored <code>setScreenAndShow(new InventoryScreen())</code> call in the ✕ button handler alongside the network packet dispatch.</li>
</ul>

<br>

<blockquote>
This hotfix resolves two regressions from v1.0.13: the duplicate close button on the cosmetic inventory screen and the non-functional ✕ button that wasn't switching back to the normal inventory.
</blockquote>
